# FORGE Engine

> Farming Operations & Regional Growth Engine

FORGE is a gameplay framework for Farming Simulator 25 that transforms roleplay into gameplay through careers, companies, projects, communications, banking and a living world simulation.

---

## Vision

FORGE is designed so that players eventually forget they are playing a mod.

Instead of pretending to be a contractor, transporter, landscaper or construction company, FORGE provides real gameplay systems that support those professions.

Every payment should have a believable source.

Every project should have a believable client.

Every piece of equipment should have a purpose.

---

## Core Principles

- Multiplayer First
- Data Driven
- XML before Lua
- Modular
- Server Authoritative
- Savegame Embedded
- Realistic, not tedious
